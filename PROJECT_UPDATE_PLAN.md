# Smart Livestock Health Monitoring System

## Weekly Status Update Plan

You will send status updates every Monday and Friday for the next 12 months. Each update should include:

- Summary of completed work since the last update
- Current progress and activities in progress
- Planned next steps for the coming days
- Any risks, blockers, or dependencies
- Important code, data, or deployment changes

---

## Update Cadence

### Monday update

Purpose: provide work completed from the previous week and planned activities for the coming week.

Include:
- Key work completed during the prior week
- Results from data ingestion, processing, storage, or monitoring work
- Any validation or testing completed
- Planned items for the current week
- Notes on collaboration with backend / DevOps / QA

### Friday update

Purpose: share end-of-week status, progress on ongoing tasks, and next steps for Monday.

Include:
- What was completed this week
- What remains in progress
- Any issues found and mitigation status
- Preparation for next week

## GitHub / Code Update Process

When you make changes to the project, follow this process:

1. Update code or documentation in the repository.
2. Add a short summary of the change in the email update.
3. Commit with a descriptive message, for example:
   - `git add .`
   - `git commit -m "Add weekly status update plan and project documentation"
4. Push to GitHub using:
   - `git push origin main`

If there is a code change or new script, mention it clearly in the Friday update so the manager knows the project progress and next development milestone.
